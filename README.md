# Automatic Washing Machine Using Verilog on VIVADO

## Introduction
Various day-to-day life systems can be represented using a Finite State Machine (FSM), and an automated washing machine is one of the best examples. FSM is a theoretical model used in digital electronics and computer systems where the machine can exist in only one state at a particular instant of time. The machine changes from one state to another depending on given inputs, and this process is known as state transition.

An FSM is defined by a set of states, an initial state, and the inputs responsible for triggering transitions between states. In an automatic washing machine, different operations such as adding water, adding detergent, washing, rinsing, and draining can be represented as individual states.

This project demonstrates the design and implementation of an Automatic Washing Machine using FSM in Verilog HDL. A testbench is also developed to verify the operation and transition of states in the washing process.
